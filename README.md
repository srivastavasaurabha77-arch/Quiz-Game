
# Quiz Game

A simple Quiz Game developed using Python. This project is a menu-driven console application where users can answer multiple-choice Python questions and check their score.

The project is designed to improve programming logic and understanding of Python concepts such as dictionaries, loops, conditions, and string handling.

---

## Features

* Multiple Choice Questions
* Score Calculation
* Menu Driven System
* Question Numbering
* Answer Validation
* User Friendly Console Interface

## How It Works

The game stores questions, options, and answers using nested dictionaries.

Example:

```python
questions = {
    "Question": {
        "options": ["A", "B", "C", "D"],
        "answer": "B"
    }
}
```
